# owl/bear - An Antweight Combo Undercutter/Thwack Combat Robot.

owl/bear is a (relatively) affordable horizontal spinner robot built for the antweight (1lb) class. Its unique feature is the ability to really quickly switch between a standard, tightly packaged undercutter and a high-mobility thwack archetype. It is mostly fabricated with 3D printing, using purchased parts as accessible as possible for Canadian teams. ~ :3 ~
